# The World Today — Monday, 23 November 2026

A program that writes one image summing up the world's news of
Monday, 23 November 2026, to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` beside it to the output directory.
It uses the Node standard library only, makes no network requests,
and writes the same bytes on every run.

## What the image shows

Six stories from 23 November 2026, researched from that day's
news reports:

- **Iran war escalates** — Trump says Iran wants a "real deal,
  not a fake deal." Iranian missiles hit Bahrain and US bases;
  three oil tankers are attacked in the Strait of Hormuz.
- **COP31 collapses** — the longest climate talks ever end in
  Antalya with no deal, split over fossil fuels; the EU rejects
  the final draft.
- **Ukraine: strikes kill 15** — Russian strikes hit flats in
  Dymer, Kyiv region; a kindergarten is hit in Kharkiv; Ukraine
  sinks a Russian warship off Benghazi, Libya.
- **NATO alert** — three Russian cruise missiles enter Poland;
  NATO holds emergency talks.
- **US: Democrats win big** — Democrats win their largest House
  majority in decades, 258 seats; Trump moves to block oversight.
- **Captured in Mexico** — troops capture Sinaloa cartel boss
  "Chapo Isidro." Also: an Indonesia factory fire kills 3, and
  Alcaraz wins the ATP Finals.
